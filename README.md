# 一件一件 · Android 待办清单 2.3

根据同目录《待办清单APP功能需求文档.md》及后续使用反馈开发。中文界面，离线使用，Java + 原生 Android Views，Room 数据库。

## 安装与运行

- APK：`app/build/outputs/apk/debug/app-debug.apk`。传到 Android 8.0 及以上手机，直接覆盖旧版安装，保留事项；请勿先卸载。
- Android Studio → Open → 打开 `C:\Project\AndroidStudio\ToDoList` → 等待 Gradle 同步 → 选择 app → Run。
- Gradle JDK 使用 Android Studio 自带的 Embedded JDK / jbr；SDK 为 API 37。
- 依赖版本：AGP 9.3.3、Gradle 9.5.0、Room 2.8.4，Java 17 源码级别。
- 当前 APK 为开发签名调试包，正式发布需要配置发布签名。

PowerShell 构建：

```powershell
$env:JAVA_HOME='C:/Program Files/Android/Android Studio/jbr'
./gradlew.bat :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
```

## 使用

### 清单

小字日期、全部/待完成/已完成筛选、带边框的新增按钮。新事项默认分类为“学习”，可改为工作、生活或自定义；支持高/中/低优先级和可选截止时间。点击事项完成或恢复待办；菜单或长按可以编辑、删除；右滑完成、左滑删除。完成、删除后不再显示底部提示栏。点已完成事项可恢复待办，删除事项可从回收站恢复。

清单按“今天”展示：今天完成的事项会暂时留在列表末尾，第二天自动从当前清单隐藏；原记录仍保留在数据库中，可在对应日期的月历、月历图片和统计中查看。

“添加到桌面”仅保留在首页。点击后直接进入系统添加确认，不再选择尺寸，默认添加 2×2 组件；长按桌面上的组件后拖动边框即可调整大小。所有组件都能按桌面允许的网格横向、纵向调整；实际屏幕占比因桌面总列数而异。组件直接打勾完成，行高和边距已紧凑化。

### 全屏月历

月历网格填满顶部月份栏与底部导航之间的主要区域；一个日期一格，直接显示当天已完成的任务标题。

- 点击空白处或日期选中该日：粗绿色边框、淡绿色整格底色、实色日期栏。
- 内容超过当前格子容量时，底部显示“＋剩余数量”。
- 点击任务、点击“＋”、长按日期或点击底部“查看当天”，可打开当天所有已完成任务的列表；再点任务可编辑、恢复待办或删除。
- 月份前后切换及“今天”定位保留。
- 按实际完成日期统计，恢复为待办或移入回收站后，不再显示在完成日历；从回收站恢复已完成事项时回到原来的完成日期。
- 容量随可用屏幕高度和字体大小变化。长标题在格内最多两行，完整内容可在详情/编辑中查看。

参考方向来自用户指定的[指尖时光公开应用展示](https://play.google.com/store/apps/details?id=com.zjzy.calendartime)，本项目实现为独立代码，未接入该产品服务。

### 统计

保留本周、本月、累计完成数及最近七天分布。

### 简洁设置

仅保留四项：

1. 深色模式：选择保存到本机。
2. 截止提醒：打开系统通知权限管理。
3. 回收站：恢复或彻底删除。
4. 导出月历图片：选择年月，保存 PNG 到系统文件选择器指定的位置。

原来的 JSON 备份恢复已按需求移除。导出月历图片是用于查看或分享的视觉总览，不能重新导入成事项。

### 回收站

普通删除只记录删除时间，数据保留到主动彻底删除；没有自动清理期限。回收站中的事项不出现在清单、月历、统计或桌面组件，也不会触发提醒。恢复会保留原分类、截止时间和完成状态；未完成且截止时间仍在未来的事项重新安排提醒。彻底删除前二次确认，确认后无法恢复。2.0 以前已经彻底删除的数据无法补回。

### 导出月历图片

设置 → 导出月历图片 → 选择年份月份 → 保存图片 → 选择保存位置。生成 2100 像素宽 PNG，不依赖屏幕截图尺寸，可保存后通过手机文件管理器分享。

图片是月历总览，每格最多展示 5 条任务，多余任务以“＋数量”明确标记。与应用一样只包含未删除的已完成事项。取消文件选择不会更改事项。

## 提醒与数据

- 使用 Room 本地数据库及后台单线程队列。
- 数据库从版本 1 升到 2 时通过迁移增加可空的 deletedAt 字段，保留既有数据，不使用删除数据库重建的方式。
- 截止提醒通过 AlarmManager 非精确闹钟在到期前约 15 分钟安排；不足 15 分钟则尽快提醒。省电、Doze 和厂商后台策略可能延迟提醒，不保证准点。
- Android 13 以上需要通知权限。拒绝不影响事项保存。
- 已完成、移入回收站的事项会取消提醒；重启、应用升级及系统时间调整时重新安排未完成且未到期的提醒。
- 卸载应用会删除本地数据；回收站仅用于应用内删除的恢复，不替代设备备份。
- 云端账号同步尚未接入。

## 核心文件

- MainActivity.java：首页、月历工具栏、日详情、精简设置、回收站和图片保存入口。
- MonthGrid.java：按屏幕空间排布日期格、显示任务和溢出按钮、选择高亮。
- MonthImage.java：高分辨率 PNG 月历总览。
- Task.java / TaskDao.java / TodoDb.java：实体、软删除查询和数据库迁移。
- TodoWidget.java 与尺寸子类：桌面组件及六种初始尺寸。
- Reminders.java / ReminderReceiver.java：提醒与恢复调度。
- app/schemas：数据库 v1、v2 结构快照。
- AI_STUDY_NOTES.md：关键实现概念。
- TEST_REPORT.md：各版本检查记录。
